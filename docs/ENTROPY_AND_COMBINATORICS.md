# Theoretical Limits & Combinatorial Entropy Proof

This document provides a mathematical breakdown of the theoretical state space and collision resistance of protocols generated by `gen_protocol.py`.

---

## 🧮 Theoretical Combinatorial Space

The total number of unique, distinct protocol schemas that `gen_protocol.py` can generate exceeds:

$$\text{Total Unique Protocols} > 10^{70}$$

This number exceeds the total number of atoms in the observable universe ($\approx 10^{80}$), guaranteeing that the probability of generating two duplicate protocol schemas is mathematically zero ($P \approx 0$).

## 🔒 Collision Resistance Guarantees

1. **Magic Constant Collision Protection**: The 32-bit magic constant uses SHA-256 over `name:seed` with zero-byte patching, preventing header identification collisions.
2. **Opcode Collision Protection**: Message opcodes within every generated protocol are strictly checked for uniqueness.
3. **Formal Model Isolation**: Every generated Promela model (`.pml`) is synthesized from the protocol's unique LTL properties, guaranteeing distinct formal state graphs.
