## 🔒 Collision Resistance & Invariants

1. **Magic Constant Collision Protection**: The 32-bit magic constant uses SHA-256 over `name:seed` with zero-byte patching, preventing header identification collisions.
2. **Opcode Space & Wire Capacity**:
   - **Wire Format (Wire Header)**: 16-bit `uint16_t` supports `0x0001` .. `0xFFFE` ($65,534$ opcodes; `0x0000` and `0xFFFF` are reserved for internal framing markers).
   - **Random Sampling**: The random generator samples from `0x0001` .. `0x00FE` ($254$ opcodes) for compact encoding, reserving `0x00FB`..`0x00FE` for cross-chain multi-chain bridge messages.
3. **Formal Model Isolation**: Every generated Promela model (`.pml`) is synthesized from the protocol's unique LTL properties, guaranteeing distinct formal state graphs verified via SPIN.
